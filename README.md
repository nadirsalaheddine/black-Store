# 🛒 Black Store | Premium React Luxury Hub

An elite, modern, and blazing-fast e-commerce virtual interface optimized with **React 18** engine frameworks, **Tailwind CSS**, and advanced **CSS3 dynamic architectures**.

🚀 **Live Preview:** [View the Store Live](https://nadirsalahddine.github.io/black-store/)

---

## ✨ Features & Capabilities

* **Asynchronous Mock API Layer:** Simulates real-world network data fetching (`async/await`) with high-end, animated **CSS3 Skeleton Loaders** before loading content.
* **Micro-interactions & Elastic UI:** Enhanced with responsive tactile feedback (`btn-bounce`) that gives a fluid, elastic scaling effect (`scale(0.94)`) upon clicks.
* **Dynamic Theme Engine:** Instantly toggles between ultra-luxurious Dark and Elegant Light modes with persistent `localStorage` saving.
* **Multi-currency Converter:** On-the-fly monetary calculations across **DA (Algerian Dinar)**, **USD ($)**, and **EUR (€)** based on accurate conversion nodes.
* **Multilingual Localization System:** Full, reactive dictionary supporting 4 languages: **Arabic (RTL layout ready)**, **English**, **French**, and **Italian**.
* **Modern CSS3 Glassmorphism:** Sleek frosted-glass paneling using advanced `backdrop-filter: blur(12px)` and consistent curved geometry (`border-radius: 16px`).

---

## 🛠️ Built With (Tech Stack)

* **Core Engine:** [React 18](https://react.dev/) (State & Effect Management Hooks)
* **Styling Framework:** [Tailwind CSS v4](https://tailwindcss.com/)
* **Compiler & Bundler:** [Babel Standalone](https://babeljs.io/) (Instant JSX runtime transformation)
* **Icons & Fonts:** FontAwesome v6.4 & Google Fonts (Plus Jakarta Sans / Cairo)
